# Mission

Career OS exists to help its one user secure a suitable full-time job in the United States.
It is not a job tracker. Every feature is judged by whether it improves that outcome.

The authoritative brief is `CAREER_OS_MASTER_MISSION_SPEC.md` (kept local, not in the public
repository, because it contains personal context). The rules that never bend:

1. **Hard eligibility comes first.** US location, full-time, early career (0 to 1 years),
   currently open, and no posting that rules out sponsorship. A ranking score can never
   override a failed hard rule. See `docs/ELIGIBILITY_RULES.md`.
2. **Sponsorship is evidence, not a guess.** Levels A, B, C, D and U, each with a source, a
   quote where one exists, and a date. No numeric probability. See
   `docs/SPONSORSHIP_EVIDENCE.md`.
3. **Unknown is a first-class answer.** Unverified roles sit in a labelled queue; they are
   never mixed into the eligible list.
4. **The candidate acts, the system prepares.** No automatic applications, messages, or
   answers to work-authorization questions. See `docs/SECURITY_AND_COMPLIANCE.md`.
5. **No false progress.** No mock listings, invented dates, or padded digests.

Quality over volume: fewer, well-targeted applications to roles with a plausible sponsorship
path beat hundreds of generic ones.
